# AI Reel Script Generator

An AI-powered application that generates short-form social media reel scripts from a user-provided topic.

## Tech Stack

- React.js
- FastAPI
- Python
- Generative AI / LLM
- NLP / text preprocessing
- REST API

## Architecture

React.js
↓
FastAPI
↓
Script Service
↓
AI Service
↓
AI Provider
↓
Generated Reel Script
